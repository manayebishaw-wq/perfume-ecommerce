# Perfume e-commerce website

This project is a modern fragrance storefront built with Next.js and Tailwind-inspired custom CSS.

## Features
- Luxury landing page
- Curated product catalog
- Product detail pages
- Shopping cart summary
- Member login page
- Admin dashboard mockup
- Responsive UI for mobile and desktop

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Tech stack
- Next.js
- React
- TypeScript
- CSS
